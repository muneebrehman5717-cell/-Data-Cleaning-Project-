 ## About This Project

This project demonstrates my foundational skills in data cleaning and exploratory data analysis using Python, Pandas, and SQL.

## Skills Demonstrated

· Python: Data manipulation and cleaning.
· Pandas: Handling missing values, filtering data, and data transformation.
· SQL: Writing queries to extract and analyze data.
· Data Analysis: Finding meaningful insights from raw datasets.

## Goal

To take a raw, messy dataset and transform it into a clean, structured format that is ready for analysis
